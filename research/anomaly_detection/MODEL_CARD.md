# 최신 모델 카드 — #80

## 단기: 단일 IF·K-means·LOF

파일: `reports/shared_model_v7/release/handoff/*_shared.joblib`.
모델별 추정기는 1개이며 Adapter 전문 모델이나 알고리즘 간 앙상블은 없다.
정상 집단 기준·최근 이력·보정은 포함한다. 점수가 1을 초과하면 경보이며 장애 확률은 아니다.
하드룰은 별도 코드이며 모델 호출에 자동 적용되지 않는다.

| 모델 | Accuracy | Precision | Recall | F1 | FPR |
|---|---:|---:|---:|---:|---:|
| IF | 94.007% | 90.326% | 73.001% | 80.745% | 1.626% |
| K-means | 93.663% | 92.932% | 68.383% | 78.790% | 1.081% |
| LOF | 93.809% | 89.597% | 72.441% | 80.111% | 1.749% |

5개 시나리오의 분 단위 판정 전체 합산이다. 시나리오별 단순 평균과 다른 지표다.
관측 F1 강점은 IF 개별 지연, K-means 집단 지연, LOF 점진적 악화다.
합성 정상 트래픽 이력·통계 신호 결합·개발 정답으로 선택한 보정 효과를 포함한다.
알고리즘 자체만의 우월성이나 실제 장애 성능으로 일반화하지 않는다.

## 장기: 선택한 n시간 내부의 추세·수준 변화

파일: `reports/long_term_anomaly/five_minute_localized/models_portable.joblib`.
1·4·8·12·24시간을 선택하고 내부에서 5분 집계한다. 정상 경험 분포 점수와 시간별 근거를 결합한다.
선택 구간 밖 감시 상태는 이어 쓰지 않지만 미리 고정한 28일 정상 참고는 별도로 필요하다.
아래는 모델 고정 후 생성한 확인용 반합성 576개 사례의 **시나리오별 지표 중앙값**이다.

| 구간 | Accuracy | Precision | Recall | F1 | 최대 시나리오 FPR |
|---|---:|---:|---:|---:|---:|
| 1h | 92.90% | 80.47% | 76.39% | 76.96% | 4.10% |
| 4h | 94.89% | 96.73% | 69.97% | 80.78% | 0.66% |
| 8h | 95.52% | 98.01% | 73.12% | 83.43% | 0.45% |
| 12h | 95.56% | 97.98% | 73.41% | 83.64% | 0.36% |
| 24h | 95.23% | 98.32% | 71.23% | 82.24% | 0.32% |

모든 개별 시나리오가 이 수치 이상이라는 뜻은 아니다. 4h Recall 중앙값은 69.97%이므로
모든 조건에서 70% 이상 달성으로 표기하면 안 된다. 원본에는 검토된 연속 28일 정상 참고가 없어 운영 실증은 별도다.

## 재현·사용 제한

- 원래 모델 바이트 변경 없음. `latest_inventory.json`과 각 원래 manifest로 해시 확인
- Python 및 sklearn/numpy/joblib 버전 일치 필요. 신뢰할 수 없는 pickle 사용 금지
- 모델 학습 참고에는 원본으로부터 얻은 ID·수치 통계가 포함될 수 있음
- 원래 학습·개발 선택의 완전 재현에는 보류된 데이터·중간 산출물 필요
- 새 데이터 baseline은 별도 버전으로 저장·재평가하며 기존 성능을 표시하지 않음
- 실제 운영 배포·새 도메인 성능·인과 설명·오탐률의 이론적 보장 없음
