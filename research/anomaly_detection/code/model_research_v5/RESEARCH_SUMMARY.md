# 추가 모델 개선 연구 결과

## 결론

IF 전체 모델은 **경보 정확성과 오탐을 개선**했다. 반면 K-means 종합 성능 개선은 실패했으므로 v4를 보존한다.
전체 모델·Adapter 모델·앙상블 어느 하나가 항상 더 좋다는 결론은 나오지 않았다.
모든 수치는 원래 합성 평가셋의 2,167,766개 **1분 의사결정**을 기준으로 한다.

| 경로 | v4 F1 | v7 F1 | F1 변화 | v4 정상 오탐 | v7 정상 오탐 |
|---|---:|---:|---:|---:|---:|
| IF 전체 | 23.28% | 25.95% | +2.66%p | 5.70% | 1.37% |
| IF Adapter | 22.43% | 21.33% | -1.10%p | 4.52% | 1.38% |
| IF 앙상블 | 23.55% | 24.14% | +0.59%p | 4.22% | 1.15% |
| K-means 전체 | 35.38% | 21.89% | -13.49%p | 2.80% | 1.10% |
| K-means Adapter | 31.86% | 16.16% | -15.69%p | 4.27% | 2.68% |
| K-means 앙상블 | 35.92% | 17.09% | -18.83%p | 5.15% | 2.45% |

변화는 반올림 전 수치로 계산한다. IF 전체 Precision 37.20%→69.81%, Recall 16.94%→15.93%.
즉 더 많은 이상을 잡은 것은 아니고, 덜 불필요한 경보를 내면서 F1을 소폭 높였다.
항상 정상으로 찍어도 Accuracy 83.39%이므로 Accuracy만으로 성능을 주장하지 않는다.

## 어떻게 개선했나

### 1. 논문 아이디어를 후보로 만들고 실패도 남김

- [Extended Isolation Forest](https://arxiv.org/abs/1811.02141): 축 정렬 편향을 줄이는 회전 아이디어를 4개 블록 회전 IF로 시험.
  full 초평면 EIF가 아니며 선택된 v7은 일반 IF다.
- [NCAD](https://arxiv.org/abs/2107.07702): 과거 맥락과 현재 구간 비교를 참고해 과거 지연 대비 변화·추세·EWMA 피처를 시험.
  논문의 신경망/학습법을 재현한 것은 아니다.
- [LOF](https://doi.org/10.1145/335191.335388): 주변 정상 이웃 대비 밀도 모델을 새 검증 사례에서 실제 실행.
  Adapter 확인 F1 47.04%였지만 정상 오탐 21.66%, 전체/앙상블 F1 1.47%/1.59%로 채택하지 않음.
- [ECOD](https://arxiv.org/abs/2201.00382)와 [SPOT/EVT](https://www.amossys.fr/wp-content/uploads/anomaly-detection-with-evt-1.pdf): 꼬리 점수/threshold 방법 검토.
  이번 구현의 경험적 분위수·채널 보정을 ECOD나 SPOT 재현이라고 부르지 않음.

v5 피처 일괄 변경은 IF의 과도한 보수화, K-means 오탐 증가를 일으켰다.
v6 채널 분리는 IF의 오탐을 줄였지만 K-means의 정상 오탐이 43~55%여서 전체 구성의 개선이라고 볼 수 없었다.

### 2. v7: 정상 학습 분포의 불일치를 줄임

기존 정상 학습은 90분 연속 실행 중심인데, 개별 지연·관계 평가에는 실행 1~2개뿐인 짧은 정상 사례가 있다.
동일 정상 상태를 학습에서 거의 보지 못했으므로 정상 참고 로그에 짧은/두 실행/36분/60분 패턴을 넣었다.
지원 집단의 정상 소요시간 중앙 범위(P05~P75)를 재생하되 **학습·보정·threshold 각 원본 템플릿만 사용**, 예약 평가 원본은 제외했다.
원래 평가 CSV/라벨을 변경하거나 추가한 정상 쌍을 평가셋으로 교체하지 않았다.

정상 학습 9,593창 / 보정 11,558창 / threshold 10,358창.
이는 재생 창 수이지 독립 원본 행 수가 아니다. 원본 업무 수를 부풀려 전문가를 추가하지 않았다.
정상 fit·보정에는 이상을 주입하지 않았다.

이 방식은 **평가 생성 환경에 맞춘 합성 도메인 적응**이다. 실제 업무의 정상 꼬리 제거가 안전하다는 근거는 아니다.
데이터·피처·threshold가 동시에 달라졌으므로 각 변경 하나의 인과적 성능 기여를 분리해 주장하지 않는다.

### 3. 하이퍼파라미터/피처 선택

v7 IF: 128 trees, max_samples=256, 일반 IF, 시간·트래픽/지연 temporal 18피처,
초기 5분/steady별 정상 P99 threshold, 전체 가중치 0.75 / Adapter 0.25.

v7 K-means: K=6, n_init=5, batch_size=2048, max_iter=100,
relational 16피처, 군집별 정상 P95 반경 거리, outer 정상 P99.9 threshold,
전체 가중치 0.25 / Adapter 0.75, phase별 threshold 없음.
클러스터 모양(축별 RMS) 보정도 시험했지만 최종 선택하지 않았다.

IF 192 / K-means 288 운용점을 새 탐색 720사례에서 비교한 뒤 독립 확인 720사례에서 1회 평가했다.
각 시나리오/경로 정상 오탐 ≤5%를 요구했고 IF는 만족, K-means는 최소 최악 오탐 5.02%로 근소하게 초과했다.
확인 집단의 v7 전체 IF F1 24.69%→27.90%, 오탐 5.48%→1.34%로 같은 방향을 보였다.
K-means는 확인 결과에서도 종합 개선되지 않았다. 확인/기존 최종/Hard 결과로 재튜닝하지 않았다.

## 모델별 실제 특징

| 구분 | 탐지 방식 | 이번 결과의 특징 |
|---|---|---|
| IF | 정상에서 드물고 쉽게 분리되는 조합 | v7 전체 폭주 F1 45.64%/정상 오탐 2.28%, 중단 78.01%/오탐 0.91%; 개별 지연·관계 기본 시나리오는 F1 0% |
| K-means | 정상 군집 중심에서 벗어나는 정도 | v4 전체 집단 지연 F1 59.61%/정상 오탐 9.80%, 중단 74.34%/오탐 0.50%; 새 v7은 관계·개별 지연에 더 민감하지만 종합 하락 |
| 전체 | 전체 패턴으로 판단, 신규 Adapter fallback | v7 IF 전체 F1 25.95%로 Adapter/앙상블보다 높음 |
| Adapter | 동일 큰 역할 안의 패턴 비교 | 지원 전문가 5개. 같은 Adapter도 업무·처리량이 달라 잘못된 국소 기준이 생길 수 있음 |
| 앙상블 | 정상 기준 정규화한 전체/Adapter 점수의 가중합 | IF는 오탐 1.15%로 더 낮지만 전체보다 Recall/F1도 낮음. 무조건 상위 모델 아님 |

v7 K-means 전체 컬럼 관계 F1 6.97%→22.52% **동시에 오탐 0.00%→1.89%**.
개별 지연 F1 9.62%→17.63% **동시에 오탐 0.29%→1.17%**.
따라서 관계/지연 특화 연구 후보이지 전체 탐지기의 대체 버전이 아니다.

## 3번째 모델: USAD 계열 시계열 Autoencoder

[USAD(KDD 2020)](https://www.kdd.org/kdd2020/accepted-papers/view/usad-unsupervised-anomaly-detection-on-multivariate-time-series.html)를 다음 후보로 제안한다.
IF=희귀성, K-means=정상 중심 거리, USAD=**정상적인 다변량 시간 흐름을 재구성할 수 있는지**로 역할을 나눈다.

- Process에서 만든 요청 수·처리량·지연·조건부 잔차·누락 mask의 15/30/60분 시간창 비교.
- 초기에는 통합 모델 1개, 정상 실제 이력이 충분해지면 Adapter 모델 필요성 검토.
- 정상만 학습하고 별도 정상 집단으로 재구성 threshold 보정. 주입 검증 라벨은 모델 선택에만 사용.
- 과거가 부족한 스트림은 IF fallback. 빈 창을 정상 0ms로 채우지 않음.
- 점진적 악화와 피처 간 결합 변화의 보완 가능성을 시험. **미구현·미평가이며 F1 향상 미확정**.
- 아주 짧은 개별 지연 사례는 과거 맥락이 없으므로 시간창 모델만으로 해결된다고 가정하지 않음.

[TranAD](https://arxiv.org/abs/2201.07284)는 더 복잡한 Attention 대안이다.
현재 단계에서는 작은 USAD/Autoencoder 검증으로 시간 흐름의 추가 가치부터 확인하는 편을 추천한다.

## 과장하지 않기 위한 검증과 한계

- [Kim 등(ICLR 2022)](https://arxiv.org/abs/2109.05257)를 참고해 point adjustment 없이 계산.
- [Exathlon(VLDB 2021)](https://arxiv.org/abs/2010.05073)처럼 사건·탐지·설명 평가를 구분해서 읽되 데이터/모델을 재현했다고 주장하지 않음.
- 원래 CSV 67개/이전 운영 모델 hash 검증, 동일 정답·시각·case index 확인, confusion matrix 직접 재계산.
- 신규+기존 96개 테스트 통과, 실행 노트북 31셀/6그림, 오류 출력 없음.
- 원래 합성 평가셋은 이전에도 봤으므로 새 블라인드/운영 성능이 아님. 새 검증도 원본 예약 풀/생성기를 공유.
- v7 IF 전체 정상 Hard 사례 경보 46.3%; 6종 모두 탐지한 Hard 사례는 모든 경로 0/1,000. 아직 실제 운영 배포 근거 부족.
- 원본 수백만 행 전체 학습이 아닌 정상 샘플 아카이브와 재생 실험.
- v7 연구 joblib에 실패한 K-means도 들어 있음. 운영 모델을 자동 교체하지 않았고 GitHub에 올리지 않음.

자세한 근거 표·막대·threshold 분포·시나리오·Adapter/fallback 분석은 `results.ipynb` 참고.
