# 추가 개선 최종 결과: 관측 이력별 분기 v12

## 결과

IF 전체와 K-means Adapter/앙상블은 **Accuracy·Precision·Recall·F1이 함께 올랐고 정상 오탐도 줄었다**.
다른 경로는 tradeoff가 있어 모든 모델/경로의 전면 개선이라고 주장하지 않는다.
기준은 최근 IF v7, 이전에 보존하기로 한 강한 K-means v4다. 실패한 K-means v7만 기준으로 삼지 않았다.
평가는 동일한 2,167,766개 1분 의사결정(정상 1,807,717 / 이상 360,049), 원래 CSV/정답 유지.

| 대표 경로 | 지표 | 이전 | v12 |
|---|---|---:|---:|
| IF 전체 | Accuracy | 84.89% | 85.35% |
| | Precision | 69.81% | 74.30% |
| | Recall | 15.93% | 18.00% |
| | F1 | 25.95% | 28.98% |
| | 정상 오탐 | 1.37% | 1.24% |
| K-means 앙상블 | Accuracy | 83.67% | 84.63% |
| | Precision | 51.58% | 57.59% |
| | Recall | 27.55% | 28.20% |
| | F1 | 35.92% | 37.86% |
| | 정상 오탐 | 5.15% | 4.14% |

F1 변화의 합성 사례 단위 400회 bootstrap 95% 구간: IF 전체 +2.94~+3.12%p, K-means 앙상블 +1.89~+1.99%p.
이 구간은 생성기 사례 샘플링 오차만 반영한다. 원본 템플릿 공유/적응적 연구/실제 운영 도메인 오차는 반영하지 못한다.

## 무엇을 엄밀하게 분석했나

1. **단건 지연의 관측/희석 문제**: 이전 IF는 개별 지연 F1 0%. 개별 완료 Process의 조건부 소요시간 위치를 피처로 넣어 v8 전체 88.51%를 얻었으나 종합 성능은 하락.
2. **정상 업무의 이질성**: 동일 절대 소요시간도 Adapter/ProcessID/처리량에 따라 의미가 다름. 정확한 처리량 우선 정상 분포를 저장하고 부족하면 상위 집단으로 fallback.
3. **희소 실행과 입력 중단의 혼동**: 실행 1~2개인 정상 사례의 빈 창을 이상으로 오해할 수 있음. 실제 과거의 비어 있지 않은 실행 분 수로 관측 이력을 구분.
4. **점수 결합에 의한 신호 억제**: 지연 점수에 맞춰 공통 threshold를 높이면 기존 중단 탐지가 사라짐. 이전 안정 모델 유지/결합/보정 제거 실험으로 확인.
5. **정상 보정의 대표성/일반화**: 원래 source-disjoint 정상 참고 자료와 synthetic normal proxy 보정 비교. proxy 보정은 원본 공유 위험을 명시했고 최종 v12에서는 사용하지 않음.
6. **시나리오·Adapter·관측 부족·사건 지표 분리**: 평균 지표에 숨겨진 집단 지연 오탐과 Hard 미탐을 확인. 미평가 창도 성능 분모에 남김.

## 최종 개선 구조

현재까지 관측한 **직전 비어 있지 않은 실행 분이 3개 미만**:

- 조건부 소요시간/완료 로그 피처에 강한 동결 v8 모델 사용.
- 개별 Process가 과거 분 이력이 없더라도 정상 학습 참고 집단이 있으면 평가.

3개 이상:

- IF는 안정 패턴+조건부 분기 v10 사용.
- K-means는 집단 지연/중단에 더 강했던 v4 유지.

이는 정상/이상 시나리오 이름이나 정답으로 경로를 고르는 방식이 아니다. 현재까지 관측한 실행 수만 사용한다.
새 모델을 무조건 대체하거나 점수 OR로 합치지 않고, **관측 조건에 맞는 검증된 분기**를 사용한다.
신규/미지원 Adapter는 선택된 분기의 전체 점수·threshold와 정확히 같은 fallback.

## 피처와 하이퍼파라미터

- 정상 train의 `(Adapter, ProcessID, totalCount)` 소요시간 경험적 분포. 원본 20행 미만이면 `(Adapter,count)`→`(Adapter,Process)`→`Adapter`→전체.
- 위/아래 꼬리에 동률을 포함한 add-one 보정, `-log(tail)` 피처. 통계 참고값이며 확정 이상 하드 룰이나 보장된 p-value가 아님.
- 완료시각 `<현재 분 종료`인 로그만 사용. 미래 종료시간/시나리오/주입 강도/총 사례 길이는 모델 입력에서 제외.
- 개별 꼬리 최대값, 5분 평균/최대, 과거 변화/EWMA/prefix 대비 변화 후보.
- IF max_samples 256/1024/4096, 128 trees/채널; K=6/12, radius/diagonal/full covariance 거리 후보 비교.
- 초기/steady 보정, 정상 분위수, 전체/Adapter 가중치, 채널 가중치, mean/max 결합 비교.
- 최종 v12는 새 트리/threshold를 학습하지 않고 기존 동결 분기를 사용. 각 분기의 선택 설정/실제 threshold는 노트북에 기록.

논문 참고: [COPOD(ICDM 2020)](https://arxiv.org/abs/2009.09463)의 경험적 꼬리 아이디어, [NCAD](https://arxiv.org/abs/2107.07702)의 과거 맥락 비교,
[Kim 등(ICLR 2022)](https://arxiv.org/abs/2109.05257)의 엄격한 평가 참고. COPOD/NCAD 알고리즘을 재현했다고 주장하지 않는다.

## 시나리오별 개선과 한계

- IF 전체 개별 지연 F1 **0%→88.51%**, 해당 정상 오탐 **0.53%**.
- IF 전체 컬럼 관계 F1 **0%→22.37%**, 해당 정상 오탐 **0.31%**.
- IF 전체 집단 지연 F1 **2.11%→17.43%**, 해당 정상 오탐 **2.13%**.
- K-means 앙상블 개별 지연 F1 **12.02%→72.58%**, 해당 정상 오탐 **0.41%**.
- K-means 앙상블 컬럼 관계 F1 **5.61%→16.13%**, 해당 정상 오탐 **0.00%**.
- 기존 중단 탐지 유지: IF 전체 **76.11%**, K-means 앙상블 **74.55%** F1.
- 점진적 악화는 IF 전체 **0.87%**, K-means 앙상블 **8.92%** F1로 여전히 매우 약함.
- K-means 앙상블 집단 지연 정상 오탐 **12.18%**. 전체 4.14%로 좋아졌다고 모든 업무가 안전한 것은 아님.
- 혼합 Hard에서 6종 전부 탐지: K-means 앙상블 **4/1,000**, 나머지 경로 0. 복합/미세 시계열 변화는 미해결.

## 검증과 전달

v12 구조를 동결한 뒤 새로운 **1,440개 주입 사례+1,440개 정상 사례**를 확인용으로만 평가했다. 재선택하지 않았다.
정상 tree/center fit 및 threshold 참고 집단의 원본 예약 템플릿 제외를 유지했다.
그러나 원래 평가셋은 이전에도 보았고 새로운 확인 사례도 원본 예약 풀/생성기를 공유한다. 새 외부 blind/실제 운영 성능이 아니다.

111개 단위/회귀 테스트 통과, 원래 정답·시각·case index 동일성, confusion matrix 직접 재계산,
엄격한 `margin>0`, 미지원 Adapter의 정확한 fallback, 400회 paired-case bootstrap 검증.
portable handoff는 각 알고리즘 600개 저장 예측을 새 Python 프로세스에서 재현했다.
기존 CSV/운영 v1/backend/GitHub/Notion은 변경하지 않았다.

모델: `reports/model_research_v12/handoff/if_v12_candidate.joblib`(11,773,977 bytes),
`kmeans_v12_candidate.joblib`(605,016 bytes). 신뢰된 SHA256를 확인하고 로드해야 한다.
실제 운영에는 synthetic traffic prior 대신 실제 이력 검증과 state 유지/빈 창/지연 도착/수집 장애 처리가 필요하다.

실행된 `results.ipynb`에 6개 경로의 전체 표, 막대/threshold 분포, 시나리오·Adapter·관측 상태·Hard 결과와 실패한 실험까지 포함했다.
