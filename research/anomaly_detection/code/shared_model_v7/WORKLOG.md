## 사용자 추가 요청: 원하는 모델별 강점

- IF: 개별 지연 / K-means: 집단 지연 / LOF: 점진적 악화. 나머지 시나리오는 특정 모델의 1등을 요구하지 않음
- 모든 시나리오의 기존 지표 비퇴보·Recall 55%·FPR 제한이 우선이며, 이를 통과한 후보에서 원하는 시나리오의 F1을 우선 비교. Precision·Recall도 함께 공개
- `role_context.py`: 최대 8개 과거 완료 관측 분의 소요시간 잔차 trajectory, 양의 기울기·선형성·증가 지속·가속도. paired 스트림 초기화, 과거 방향만 사용, 미래 값/이벤트 경계/시나리오 정답 미사용
- `role_models.py`: IF 개별 실행 정상 근방+소요시간 꼬리, K-means 최근 지연 집단의 평균·지속·완료 규모, LOF 정상 이웃 대비 최근 trajectory를 강조하는 후보. 각 모델은 다른 시나리오를 위한 피처도 유지
- `exact_policy.py`: 원하는 task F1을 우선하는 선택 목적 추가. 다른 task의 지표 제약을 완화하지 않는지 별도 테스트
- `role_priority.py` 및 전체 평가기: 실제 전체 F1 순위와 차이를 공개. 원하는 모델이 실제 우위가 아니면 역할 달성으로 표시하지 않음. 다른 모델을 고의로 약화하지 않음
- 현재 23개 단위 테스트 통과. 목표 Recall·비퇴보와 역할 우위의 전체 달성은 아직 검증되지 않음. 역할 특화 후보는 미채택 연구 상태

## 오탐률 조건의 명시적 완화 및 채택 절차

- `assemble_attempt.py`: 완료된 평가와 동결 모델을 해시 검증 후 복사. 새로운 점수 조정 없음. 조합한 결과는 sklearn·raw Process 입력의 새 독립 감사 필수
