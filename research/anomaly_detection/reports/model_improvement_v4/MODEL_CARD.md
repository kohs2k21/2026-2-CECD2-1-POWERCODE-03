# 개선 모델 v4 결과

연구 후보이며 운영 v1을 교체하지 않았다. 기존 7개 합성 평가셋의 **2,167,766개 1분 의사결정**을 그대로 평가했다.
정상 1,807,717개, 이상 360,049개. Process 행 분류의 성능이 아니다.

## 개선 전후

| 전략 | 기존 F1 | v4 F1 | 기존 정상 오탐 | v4 정상 오탐 |
|---|---:|---:|---:|---:|
| IF 전체 | 22.01% | 23.28% | 2.99% | 5.70% |
| IF Adapter | 19.29% | 22.43% | 2.79% | 4.52% |
| IF 앙상블 | 22.54% | 23.55% | 3.28% | 4.22% |
| Clustering 전체 | 14.95% | 35.38% | 3.46% | 2.80% |
| Clustering Adapter | 17.52% | 31.86% | 4.50% | 4.27% |
| Clustering 앙상블 | 17.44% | 35.92% | 4.29% | 5.15% |

가장 명확한 합산 개선은 Clustering 전체 모델: F1 상승과 정상 오탐 감소가 함께 나타났다.
IF 앙상블의 F1 상승은 1.01%p이며 오탐이 늘었다. IF가 압도적으로 개선됐다고 해석하지 않는다.
Clustering 앙상블은 전체 모델보다 Recall이 높지만 오탐도 더 높다. Adapter 모델/앙상블이 항상 더 좋은 것은 아니다.

## 관측된 역할

- 선택 구성에서 시간대 폭주: IF 앙상블 F1 44.60%, Clustering 앙상블 32.09%
- 집단 지연: IF 앙상블 1.57%, Clustering 앙상블 57.80%
- 입력 중단: IF 전체 77.00%, Clustering 앙상블 74.90%. 전체 모델도 충분히 역할을 함
- 혼합 Hard: IF 앙상블 8.78%, Clustering 앙상블 23.82%
- Hard 6가지 모두 탐지: Clustering 앙상블 4/1,000사례(0.4%), 나머지 0. 대부분의 복합 이상을 모두 해결하지 못함

IF는 기존+관계 피처 16개, Clustering은 기존+시계열 피처 18개를 검증 탐색으로 선택했다.
따라서 위 차이는 알고리즘만의 차이가 아니다. 동일 관계 피처/기본 설정/확인용 정상 오탐 1% 보정으로 통제한 진단도 별도 제공한다.
통제 진단에서 전체 모델 F1은 IF 16.11%, Clustering 10.22%로 순위가 바뀐다. 피처·운영점 선택 효과를 분리해야 한다.

## 중요한 실패

- 개별 지연: 선택 IF 앙상블 정상 오탐 44.89%. F1 7.07%
- 컬럼 관계: 선택 IF 앙상블 정상 오탐 38.41%. F1 5.27%
- 점진적 악화: 선택 Clustering 앙상블 F1 8.96%로 여전히 약하며 기존 최선보다 저하
- 별도 확인용 집단에서 Clustering Adapter/앙상블 오탐 약 10%, IF 전체/Adapter 약 5.5%로 탐색 오탐 제약을 초과

합산 수치만으로 모든 시나리오/업무에 안정적이라고 결론내리면 안 된다.
소규모 확인 집단·공유 원본 템플릿/생성기·예전부터 확인한 합성 평가셋이라는 제약도 있다.
