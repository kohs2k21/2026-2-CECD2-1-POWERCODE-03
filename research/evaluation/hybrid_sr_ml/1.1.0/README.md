- 46,815거래: 최종 경고738·비경고46,077·최종 평가 불가0
- 분모0 대체 후에도 개별 수치 규칙이 불가인25거래는 다른 방법의 경고에 포함

- 대체 규칙과 집계 원천은 `release_receipt.json`과 동결 모델의 RESULTS.md에 기록

## FlowBench 동결 재평가

2026-11-11 원본 TEST CSV에서 피처·탐지를 재실행했다. 590개 workflow 실행,
193,390개 작업, 주입 라벨50,940개다. 8개 피처·동결 전처리·수치/논리 SR·ML을
사용했고 fit·LLM 호출·임계값 보정은0회다. 기존 피처·점수·판정과 동일했다.

| 방법 | TP | 정밀도 | 전체 양성 재현율 | F1 |
|---|---:|---:|---:|---:|
| 수치 SR | 32,088 | 40.52% | 62.99% | 49.32% |
| ML 3종 OR | 29,763 | 37.88% | 58.43% | 45.96% |
| 최종 SR+ML OR | 32,826 | 39.10% | 64.44% | 48.67% |

논리 SR 추가 경고0개, HR은 FlowBench 평가 범위에 없다. 최종 평가 불가18,035개는
stage-in/out 원천 시간 결측이며 ESB 분모0 대체 정책을 적용하지 않았다.
Montage CPU 주입 탐지가 약하고, 주입 라벨0인 작업의 경고가 많다는 한계가 남는다.

## 공식 PyOD 구현 및 후속 정책

PCA·GMM·kNN은 2026-11-09 실제 실행의 동일 8피처·동일 TEST 결과를 재집계했다.
최종 모델은11/11 재실행, 비교 모델은11/09 실행 결과이며 이번 업로드에서 재학습하지 않았다.

| 방법·정책 | 정밀도 | 재현율 | F1 |
|---|---:|---:|---:|
| PCA 참조 p99 | 37.22% | 48.84% | 42.24% |
| GMM 참조 p99 | 38.95% | 57.00% | 46.28% |
| kNN 참조 p99 | 39.10% | 58.62% | 46.91% |
| kNN PyOD 기본(TRAIN p90) | 37.72% | 71.28% | 49.33% |
| kNN 참조 p95 후속 실험 | 39.59% | 65.95% | 49.48% |

p95는 별도 THRESHOLD 집합에서 임계값만 변경한 후속 실험이며 최종1.1.0에는 반영하지 않았다.
최종 수치 SR은 그룹별 TRAIN p95·spread + 공동 참조 p99 보정이므로 단일 모델 점수
p95/p99와 같은 구조가 아니다. 동일 경고량으로 맞춘 비교나 LLM 고유 효과 검증도 아니다.

## 분할·라벨·결측 해석

- 전체 DAG 실행 단위 분리: 각 workflow TRAIN25·CALIBRATION10·THRESHOLD5실행, 나머지 TEST
- 비주입 실행 선별에 라벨 사용, 모델·전처리 입력에서는 라벨/주입 정보/ID 수치 사용 제외
- 기존 관찰 TEST 재사용, 새 맹검 시험·새 workflow 전체 holdout 아님
- 실제 라벨 None=비주입, cpu_2/cpu_3/hdd_5/hdd_10=자원 주입 대상
- 비주입 작업도 다른 작업의 지연 전파를 받을 수 있음, 운영 오탐률·실제 장애 precision 주장 제외
- recall 분모는 전체 양성, 평가 불가 양성도 포함
- F1=2TP/(2TP+FP+비경고 양성+평가불가 양성), 두 workflow의 개수를 합산한 작업 단위 지표
- 공식 PyOD 클래스를 사용하되 기존 run 분할·TRAIN 전처리 유지, PCA 성분 수 TRAIN rank 제한
- 논문 점수 완전 재현·실시간 탐지 지연·복구 시간 평가는 아님
