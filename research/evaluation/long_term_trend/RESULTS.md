# 장기 추세 연구 결과 — Issue54

- 범위: PROCESS HR/SR/ML과 독립인 장기 추세 연구. 통제된 1분 집계 합성 자료, 실제 고객 성능·운영 심각도·SLA 검증 제외
- 결론: **SR 1시간·5분 주기를 다음 연구 기준선으로 권고. EIF 6시간은 보조 비교 후보, 운영 적용은 별도 승인**
- 최종 C5 시험: SR 41/60, IF 14/60, EIF 30/60. 두 결합군은 SR과 정확히 같은 41사건 포착, 추가 사건 0
- 별도 주기 시험: SR+EIF C1에서만 SR 대비 1사건 추가. 단일 시험의 1건 차이로 일반적 우월성 판단 불가
- 그룹별 정상 예산 초과 7/120셀 존재. 전체 평균만으로 운영 예산 충족 주장 금지

## 실험 규약

- 모델: 표준 IF·저자 EIF, 각 128트리·표본 256·CPU 1스레드. 기존 학습된 v12 가중치 재현 제외
- 피처: 기본형 31 / 추세 보완 43. SR에도 동일 43개 후보 접근, 유효한 물리 피처의 고정 정상 편차 사용
- 관측창: 1~12시간 전체, 선정 주기 C5. 모델 2 × 피처 2 × 창 12 × 난수 3 = **144학습**, 실패 0
- 그룹: 상시 업무 / 평일 업무. 난수: 11·29·47. 범주 ID·status·정답·시나리오의 모델 입력 제외
- 분할: 정상 학습 7일 → 정상 보정 7일 → 선정 14일 → 잠금 → 독립 최종 14일 / 별도 주기 시험 14일
- 학습·보정 정상은 합성 생성 가정. 실제 자료에서 status=S만으로 정상 확정 불가
- 이상: 폭주·로그 발생 중단·수준 변화·점진 증가·관계 변화. 정상: 일중/주말·허용 피크·업무량 증가·예정 휴무·등록 별칭
- 각 시험 세트 고유 60사건: 기본 51 / 자료 없음 3 / 관측 지연 3 / 새 범주 3. 모든 창은 같은 사건 재사용, 720개 독립 사건으로 해석 금지
- 당시 공개된 1분 집계만 사용, 2분 관측 지연 가정. 최대 12시간 공통 준비 mask 적용, 각 창의 운영 가동 가능 시각 검증과 구분
- 정상 보정에서 모든 그룹·C1/C5/C15의 오경보 ≤0.05/그룹시간, 정상 양성시간 ≤1%를 만족하는 strict `score > cut` 고정
- 보정 탐색: 사전 고정 quantile 후보 최대 8개. 전역 최적 판정선 탐색·동일한 시험 오경보 보장 아님
- 선정: 각 난수·그룹의 정상 예산과 유효 행 100% 점수 산출 → 시나리오 평균 탐지율 → 손실 포함 지연 → 오경보 → 짧은 창/기본 피처
- 선택: **SR 추세43/W1, IF 추세43/W11, EIF 추세43/W6**. 선정 단계 적격 상태, 운영 승인 의미 아님
- 최종·주기 시험 추가 학습 0 / 재보정 0 / 시험 결과에 따른 재선정 0
- 결합: 같은 SR 분기와 각 ML 분기의 고정 보정 margin 중 최댓값, 결합 판정선도 정상 보정으로 별도 동결. 항상 단독 OR와 동일하다는 보장 없음
