| 시나리오·판정기 | 주입 전 경보 | 주입 후 경보 | 새로 탐지 | 해석 |
|---|---:|---:|---:|---|
| P02 · SR | 3/90 | 3/90 | 0 | 신규 지연 탐지 증가 없음 |
| P02 · 예비 IF | 3/90 | 5/90 | 2 | 일부 변화에 반응; 품질 결론에 표본/정상 근거 부족 |
| P03 · SR | 90/90 | 90/90 | 0 | 원본부터 경보 |
| P03 · 예비 IF | 90/90 | 90/90 | 0 | 주입 후 100%를 합성 지연 탐지 능력으로 해석 불가 |

- 기존 recall 결과 보존; 동일 행의 주입 전/후 판정을 보조 표로 추가
- 이미 경보인 행을 결과 확인 후 제거하거나 강도를 조절하지 않음
- 확인된 정상 정답 미제공: 실제 오탐률 미산출; 성공 상태 후보의 경보율은 오탐률 아님
- 여러 어댑터 중 학습 참조의 충분한 표본으로 전용 기준선을 만든 어댑터 1개; 나머지 fallback·분포 이동 영향 구분 필요

## ADBench 보조 실험

- 공식 생성기 고정 커밋: `f7fed68dea6901fe9a81ed51b251b1d2456790cd`; 소스 SHA 검증 후 해당 함수만 실행
- 학습 피처에서 생성 기준 fit; 모드별 참조 1,000행 + 합성 이상 100행, 동일 고정 IF로 채점
- 합성 이상 탐지율: local 6% / cluster 39% / global 90%
- dependency 모드: 이번 격리 실행에서 미지원 사유 기록
- 의미: 수치 피처 공간의 스트레스 시험; 원본 ESB의 범주/건수/관계를 보장한 장애 로그 아님
