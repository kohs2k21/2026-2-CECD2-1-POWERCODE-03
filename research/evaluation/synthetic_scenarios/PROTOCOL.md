# 단일 시나리오 합성 실험 규약

2026-10-18. 운영 코드 수정·운영 서버 접속·자동 커밋/푸시 없이 연구 실험만 수행한다.

## 입력과 정답

1. GutenTAG 공식 생성기: 사인파+노이즈, 단일 채널, 정상 학습 데이터와 테스트 데이터. 테스트마다 평균 이동 구간 하나만 주입한다. 5 seed × 4 offset × 2 길이. 학습·임계값은 이상 테스트와 분리한다.
2. TSB-UAD 공식 `change_segment_add_scale(method='add')`: 원본 PROCESS의 가장 큰 동일 hub/process 그룹, 성공·완료·양의 건수·건수 일관성·유효 시각을 만족한 후보의 처리시간(ms). 완료 시점에만 처리시간을 알 수 있으므로 거래 단위 완료 시각의 겹치지 않는 블록을 대략 50/20/30%로 분할한다. 동시 완료·거래 경계를 유지하므로 실제 행 비율은 다를 수 있다. 후보 성공 상태는 정상 정답을 보증하지 않는다. train/보정/원본 test에는 tail 제거·평활화·리샘플링을 하지 않는다. 테스트 구간 하나에만 1/3/6/12초를 더한다. 주입 밖 원본 값 완전 일치 검사. 실제 기존 이상 여부는 unknown.
3. TSB-UAD flip_segment는 순서 변화만 있는 음성 대조 성격의 추가 난이도 실험이다. 점별 모델로 잡기 어려운 경우를 숨기지 않는다. 사례마다 주입 구간은 하나다.

## 모델·평가

- 신규 연구용 1D IsolationForest와 비교용 고정 median/MAD 점수. 기존 운영 모델의 재현·우위 주장 없음.
- 모델/Scaler는 train만 fit. 임계값은 별도 calibration 점수의 99분위, test를 보고 변경하지 않는다. 동일 데이터·동일 seed에 대한 원본/주입 쌍에 동일 모델·임계값을 적용한다.
- GutenTAG는 점별 Precision/Recall/F1, AP/AUC와 원본 대조 경보율, 사건 내 첫 탐지 지연(샘플)을 계산한다. point adjustment 없음.
- 실제 CSV는 injection mask 기준 탐지율과 원본 대조 경보율·주입으로 추가된 탐지 범위를 기록한다. 정밀도·F1 계산값도 주입 마스크 기준이며 고객 장애 정확도로 해석하지 않는다. 원본 구간 경보를 실제 오탐으로 확정하지 않는다.
- seed 반복은 같은 원본 test의 다른 주입 위치·모델 seed 반복이며 독립 고객 데이터 5개가 아니다.

## 연산 성능·부하

- 같은 데이터와 저장한 연구용 IF로 배치 1/32/256의 순수 추론 처리량·시간을 측정한다.
- 모델당 단일 worker, bounded 메모리 큐 512, open-loop 목표 10/100/1000/5000행/초, 조건당 8초 × 2회, drain 최대 5초. 배치 상한 1/32. 타깃 시각부터 결과까지 지연과 실제 입고 후 지연을 모두 기록한다.
- 대상: 합성 대표 사례와 실제 CSV 기반 대표 사례. 조건 순서는 고정 seed로 섞어 순서 편향을 줄인다. 부하 조건은 겹쳐 실행하지 않는다.
- offered/admitted/rejected/completed/pending/inflight·실패·최대 큐·p50/p95/p99·CPU·RSS·스케줄 지연·1초 이내 완료 비율을 전체 offered 분모와 함께 기록한다. 끝까지 처리된 건만의 p95로 성공을 주장하지 않는다.
- 이 부하는 로컬 추론+메모리 큐 실험이다. PostgreSQL·Collector HTTP·Docker 네트워크·SSE·LLM/GPU·원천 발생 시각은 포함하지 않는다. 서버의 전체 파이프라인 처리량/SLA로 외삽하지 않는다.

## 산출물

설정·소스 SHA·데이터 SHA·분할·환경·생성 시간·모델 시간·원시 결과 JSON/CSV·그림·시행착오를 저장한다. 실제 식별자/원본 CSV는 저장소에 복사하지 않는다. runs 디렉터리는 Git 제외. 사용자에게는 실제 실행 결과와 보류점을 함께 보고한다.

## 탐색 후 수정 이력

- 초기 GutenTAG import: NumPy 1.26.4에서 `np._core._type_aliases` 호환 실패. upstream 수정 없이 NumPy 2.2.6으로 환경 고정 후 정상 생성 확인.
- pilot-01: TSB import가 만든 미추적 pycache를 소스 변경으로 오인해 실행 전 거부. 추적 파일과 실제 소스 변경은 계속 거부하고, pycache만 무시하도록 수정.
- pilot-02: start-time 분할의 초벌 결과. 강한 합성 평균 이동은 잡히지만 실제 CSV +12초도 99분위 임계값에서 놓침. 완료 후 값이라는 가용성 조건에 맞춰 최종 실험은 completion-time 분할로 보완. 초벌 결과는 최종 결과로 인용하지 않는다.
- 최종 실험에 보정 점수 95분위 탐색 조건 추가. train/calibration/test는 그대로 유지하고 두 임계값 결과를 모두 공개한다. 테스트를 본 뒤 추가한 탐색이므로 95분위 결과를 독립적인 최종 검증이나 최적 임계값으로 주장하지 않는다.
