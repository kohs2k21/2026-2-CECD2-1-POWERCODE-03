# 수치·논리 SR 및 ML 연구 모델 1.1.0

Issue #142. 동결된 연구 실행 번들이다. 같은 로그에서 수치 SR, C3 논리 SR,
IF·K-means·LOF를 평가하고 OR 판정과 원천 근거를 저장한다.

- [동결 모델·규칙·코드](1.1.0/README.md)
- [실행·인수 안내](../../integration/hybrid_sr_ml/README.md)
- [집계 평가·한계](../../evaluation/hybrid_sr_ml/1.1.0/README.md)
- [공개 예시 재현](../../scenarios/hybrid_sr_ml/README.md)

| 프로필 | 피처 | 수치 SR | 주 논리 SR | 저장 ML |
|---|---|---|---|---|
| ESB | 65개 정의, ML T25/P13/M4=42개 | 42개 | 3개 | T/P/M × IF·K-means·LOF = 9개 |
| FlowBench 1000genome | 8개 | 7개 | 작업 카탈로그 참조 1개 | 3개 |
| FlowBench Montage | 8개 | 8개 | 작업 카탈로그 참조 1개 | 3개 |

ESB의 확인된 분모 0은 14개 바인딩의 실제 대체 검사를 적용한다. 원래 비율을
0으로 채우지 않으며, 대체 검사와 원천·판정·기존 엄격 판정을 함께 보존한다.
원천 결측이나 불확실한 관계는 계속 평가 불가다. 이 정책은 FlowBench의
전송 시간 결측에 적용하지 않는다.

검증된 기존 5개 LoRA와 15개 ML 파일을 포함한다. 탐지 명령은 LLM 호출,
모델 학습·다운로드·임계값 재조정을 수행하지 않는다. 선택적 명세 생성에는
사용자가 별도로 준비한 로컬 Qwen Base가 필요하다.

`1.1.0/bundle_manifest.json`의 522개 항목과 manifest 자체를 원본 바이트 그대로
보존했다. 변경은 새 버전으로 관리한다. 이전 #140 패키지와 서버 동작은 유지한다.
연구용 배치 실행 범위이며 서비스 API·DB·큐·알림·운영 배포는 별도다.
