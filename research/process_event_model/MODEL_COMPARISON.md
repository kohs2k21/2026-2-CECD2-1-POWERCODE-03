# 최신 실행 행 모델과 직전 1분 집계 모델 비교

## 바뀐 핵심

- 직전: 같은 Adapter + Process의 실행들을 1분 요약 행으로 변환한 뒤 판정
- 최신: **원본 Process 한 실행 = 한 행**을 유지하고 과거 맥락 파생변수만 추가한 뒤 판정
- 최신에서도 최근 분의 최대 지연·실행량을 내부 참고값으로 계산하지만, 원본 학습/입력 행을 분별 요약 행으로 바꾸지 않음
- 원본 Transaction ID·Process ID가 결과에 남아 조사할 실행을 직접 찾을 수 있음
- 같은 Process ID가 여러 Transaction에서 반복 실행될 수 있으며, Process ID는 실행 한 건의 고유 ID가 아님

## 동일 평가 단위 성능

각 시나리오의 개발 400사례를 제외한 확인 **4,600사례 + 대응 정상 대조군**, 같은 분 구간 정답을 사용했습니다. 아래는 F1(%)입니다.

| 시나리오 | 모델 | 직전 | 최신 | 차이(%p) |
|---|---|---:|---:|---:|
| 개별 지연 | IF | 87.51 | 89.88 | +2.37 |
| 개별 지연 | K-means | 80.01 | 84.90 | +4.90 |
| 개별 지연 | LOF | 83.05 | 85.08 | +2.03 |
| 집단 지연 | IF | 89.71 | 93.51 | +3.80 |
| 집단 지연 | K-means | 92.90 | 93.17 | +0.28 |
| 집단 지연 | LOF | 89.54 | 89.82 | +0.28 |
| 시간대 폭주 | IF | 66.78 | 67.38 | +0.60 |
| 시간대 폭주 | K-means | 67.74 | 67.43 | -0.32 |
| 시간대 폭주 | LOF | 67.02 | 65.67 | -1.34 |
| 점진적 악화 | IF | 78.03 | 81.35 | +3.32 |
| 점진적 악화 | K-means | 73.17 | 81.15 | +7.98 |
| 점진적 악화 | LOF | 80.75 | 83.97 | +3.22 |

최신 4개 시나리오 합산 결과(%)입니다. 서로 다른 크기의 시나리오 지표를 단순 평균한 값이 아니라 confusion matrix를 합산한 값입니다.

| 모델 | Accuracy | Precision | Recall | F1 | FPR |
|---|---:|---:|---:|---:|---:|
| IF | 94.28 | 90.98 | 75.10 | 82.28 | 1.60 |
| K-means | 94.20 | 90.64 | 74.89 | 82.02 | 1.66 |
| LOF | 94.15 | 87.02 | 78.61 | 82.60 | 2.52 |

모든 모델·시나리오의 F1 하락은 최대 1.3431%p, 최신 최대 FPR은 2.9069%입니다. **모든 지표가 유지·개선됐다는 뜻은 아닙니다.** 시간대 폭주 Precision은 직전보다 하락했습니다. 순수 sklearn 추정기만의 성능이 아니라 통계 보정과 경보 유지 정책을 포함한 결과입니다.

주 결과는 최종 분 단위 경보입니다. 원본 실행별 F1은 `minute_confirmation.json`의 `Process_row_metrics_secondary_only`에 별도로 있습니다. 이 행별 지표를 직전 분별 지표와 직접 비교하지 않습니다. 직전 노트북은 입력 중단 포함 5개 시나리오 전체 결과도 보여주므로, 위 부분집합 결과와 범위를 구분해야 합니다.

## 학습·피처·설정

- 실제 원본 수집 기간: 2025-12-24~2026-04-06, 2026-08-15~09-14, 2026-09-30~10-02
- 최신 sklearn 추정기 학습: 실제 원본 정상 후보 60,000행. 후보 조건은 S·오류 0·건수 정합·유효 완료 시각이며 실제 정상 보장은 아님
- 소요시간 정상 참조: Adapter·Process·처리 건수별 분포. 표본 부족 시 더 넓은 집단과 전체 분포로 대체
- 추가 요일·시간대 실행 건수 참조: 기존 합성 개발 정상 대조군 1,200세션·50,986개의 관측 범위가 알려진 분. 추정기 학습용 가상 Process 행을 만든 것은 아니지만, 모든 참조까지 원본만 사용했다고 표현하면 안 됨
- 설정·통계 결합·경보선 선택: 개발 정답 사용. 확인 사례를 추가 참조 fitting에 사용하지 않았으나, 반복 연구 벤치마크이므로 외부 블라인드 시험 아님

| 알고리즘 | 최신 고정 설정 | 추정기 입력 |
|---|---|---|
| IF | 400 trees, max_samples 128, random seed 20261030 | `native_context` 8개 |
| MiniBatch K-means | 32 clusters, batch 2048, n_init 5, whitening 없음 | `native_compact` 5개 |
| novelty LOF | 이웃 60, 참조 최대 8,192 고유 벡터 | `native_context` 8개 |

최신 공통 5개: `row_upper_tail`(정상 대비 실행 지연 희귀도), `native_latency_run`(지연 지속), `native_latency_cusum`(누적 지연), `native_traffic_llr`(실행량 변화 증거), `native_traffic_current`(현재 실행량 증가).

IF·LOF의 추가 3개: `native_latency_lift`(초기 관측 대비 지연 증가), `predictive_burst_1m`, `predictive_burst_3m`(과거 빈도 대비 최근 요청 증가). 전처리·보정에는 추정기 입력 외의 참고 피처도 사용합니다. ID 문자열·STATUS·이상 정답을 추정기 입력으로 사용하지 않습니다.

## 모델별 해석과 한계

- IF: 이번 개별 지연 F1이 가장 높음. 집단 지연도 K-means보다 조금 높으므로 역할을 맞추기 위해 순위를 바꿔 설명하지 않음
- K-means: 정상 유형으로부터의 거리 평가. 집단 지연 성능은 높지만 이 결과에서 단독 최고는 아님
- LOF: 정상 이웃과의 상대 밀도 평가. 점진적 악화 Recall·F1이 가장 높지만 합산 FPR은 세 모델 중 높음
- 시간대 폭주: 세 모델 모두 상대적으로 낮은 F1. 정상적인 빈도 변화와 장애를 구분하는 추가 검증 필요
- 입력 중단: 최신 모델 범위에서 제외. 새 로그가 전혀 없을 때 새 장애를 여는 기능은 미구현
- 운영 수초 내 지연, 중복/지연 전달, 다중 worker 상태 일치, 재시작 복구는 실제 운영 시험이 별도로 필요
- SHAP 등 개별 행의 피처 기여도 설명은 이번 전달물에서 구현한 기능이 아님

근거: `results/latest/minute_confirmation.json`, `completion_audit.json`, `live_audit.json`, `models/previous_minute/manifest.json`. 이전 및 중간 모델을 최신으로 덮어쓰지 않습니다.
