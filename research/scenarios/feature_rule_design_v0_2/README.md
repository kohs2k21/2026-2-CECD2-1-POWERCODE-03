# 피처 설계 평가 구성

[coverage.json](coverage.json)은 지정 분석8·자유 발굴8·지원 한계4의20개 사례를 구분한다. 실제 승인 원천과 통제 합성을 별도로 기록한다.

자유 발굴 입력에는 정답 후보나 특정 계산 목적을 제공하지 않았다. 지정 분석은 필터·집계 단위·요청 대상을 보존해야 한다. 후보0개가 정당한 지원 한계인지, 가능한 분석의 포기인지 구분한다.

고객 CSV·합성 행 fixture·전체 학습 교사 자료는 이 패키지에 포함하지 않는다. 공개 스키마·프로파일과 원문은 [평가 폴더](../../evaluation/feature_rule_design_v0_2/README.md)에 있다. 이 자료는 서버 실행 fixture로 자동 채택하지 않는다.
